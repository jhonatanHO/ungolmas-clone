# AdminTextarea

Campo multilínea del panel CMSNET (`packages/core/Admin/resources/assets/css/components/admin-textarea/admin-textarea.css`). Conserva la altura mínima de 80 px y el redimensionado vertical del formulario existente.

## Base

```html
<label for="description" class="admin-textarea-label">Descripción</label>
<textarea
  id="description"
  class="admin-textarea"
  name="description"
  rows="3"
  maxlength="1000"
  placeholder="Escribe una descripción..."
></textarea>
```

## Uso y estados

Hereda Light/Dark. El hover cambia únicamente el borde y Tab muestra el foco.
`readonly` conserva el acceso al contenido; `disabled` impide editar y recibir foco.
Los textos son ficticios y no se guardan. No modifica AdminInput ni los formularios de la aplicación.
