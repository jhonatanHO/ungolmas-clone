# AdminBadge

Etiqueta de estado del listado de CMSNET (`packages/core/Admin/resources/assets/css/components/admin-badge/admin-badge.css`). Conserva el fondo neutral, borde continuo y forma redondeada del listado existente.

## Base

```html
<span class="admin-badge">Activo</span>
```

## Uso

Es informativo: no recibe foco ni tiene hover de botón. El texto identifica el estado sin depender
del color. Hereda Light/Dark y no introduce colores de éxito o error que no existen en el listado.
No utiliza `role="status"` para etiquetas estáticas.
