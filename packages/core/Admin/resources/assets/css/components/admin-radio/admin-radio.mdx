# AdminRadio

Selección única del panel CMSNET (`packages/core/Admin/resources/assets/css/components/admin-radio/admin-radio.css`). Reutiliza el aspecto del control nativo y las opciones de participación del formulario existente.

## Base

```html
<fieldset class="admin-radio-group">
  <legend>Participación</legend>
  <div class="admin-radio-options">
    <label class="admin-radio">
      <input type="radio" name="participation" value="individual" checked />
      <span>Individual</span>
    </label>
    <label class="admin-radio">
      <input type="radio" name="participation" value="team" />
      <span>Por equipos</span>
    </label>
  </div>
</fieldset>
```

## Uso y estados

Comparte `name` entre opciones del mismo grupo y utiliza un nombre distinto para cada grupo.
`fieldset` y `legend` describen la selección para tecnologías de asistencia.
Prueba Tab y las flechas del teclado. Hereda Light/Dark; el hover no cambia el texto de la etiqueta.
Los ejemplos no envían datos.
