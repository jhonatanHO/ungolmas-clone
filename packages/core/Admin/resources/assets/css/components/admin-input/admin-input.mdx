# AdminInput

Componente visual base para campos de formulario del panel administrativo CMSNET (`packages/core/Admin/resources/assets/css/components/admin-input/admin-input.css`).

## Base

```html
<input type="text" class="admin-input" placeholder="Nombre de ejemplo" aria-label="Nombre" />
```
